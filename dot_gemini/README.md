# Antigravity CLI (`agy`)

Only the status line script is tracked here; `~/.gemini/antigravity-cli/settings.json` is mutated interactively by `/config` and `/statusline` and is left per-device.

## Setup (once per device)

Inside `agy`:

- Status line: `/statusline ~/.gemini/antigravity-cli/statusline.sh`
- Theme: `/config` → Color Scheme → `Terminal` (follows Ghostty's ANSI palette)
